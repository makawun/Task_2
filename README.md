# Task_2

Автотесты API сервиса Stellar Burgers на pytest + requests + allure-pytest.

## Структура

- `api/` — HTTP-клиент и обёртки над эндпоинтами
- `data/` — URL, тексты ошибок, статические данные и генераторы
- `tests/` — тесты, сгруппированные по эндпоинтам
